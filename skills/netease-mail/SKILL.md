# 网易企业邮（DSH-EMAIL）

这个部署里，网易企业邮是**真连着的**：自写 IMAP（993）+ SMTP（465），八个 `mail_*` 工具，
外加侧栏「邮箱」面板与 `/mail/api2/*` 数据面。授权码从环境变量 / 用户目录 / 插件目录三处之一取，**你不需要、也不许把授权码打进对话**。

## 先自检

拿不准连通性就先 `mail_check` —— 它一次给你：账号、IMAP/SMTP 通不通、授权码来源、
各文件夹条数、往返耗时。它不通，后面八个工具全都不通。

## 找信

- 优先 `mail_search`（`keyword` 匹配主题/发件人，必要时正文；也能用 `from` / `subject` / `sinceDays` / `unreadOnly`）。
- 中文关键词是**本地过滤**：先拉最近 `scanLimit` 封的头，再逐条比。回复里必须带上「扫了多少封、命中多少」，别只说「找到了」。
- 正文回捞有闸门：默认只翻 10 封、单封超过 3 MB 跳过、总共 8 秒预算。撞上预算时报告里会有「正文没找完」——**这句话要转达给伙伴**，别当成「没有这封信」。
- 纯 ASCII 关键词会走服务端 TEXT 条件，快得多。

## 读信

- `mail_read` 给你主题、收发人、日期、正文、附件清单。正文默认 6000 字截断，要多就给 `bodyChars`。
- 大信（> 512 KB）只取正文部件，附件不下载，附件大小是**估算**（显示成「约 X」）；报告里的【取法】行说明走的是哪条路。
- 只快速看一眼就 `markRead: false`，别手滑把人家没读的信标成已读。

## 附件

- `mail_attachment` 按 `index` 存一封里的某个附件，默认落到 `~/Downloads/mail-attachments`，可以给 `dir`。
- 文件名保持发件人原样：**别去「修」那个多出来的空格**，人家原样就是那样。
- 大附件慢在**服务器带宽**（网易实测约 1 MB/s），不是插件的问题；13 MB 的部件要十几秒，等就是了。

## 发信（对外动作，先问）

- `mail_send` 是**对外动作**：先把收件人、抄送、主题、正文（含附件清单）给伙伴过目，拿到明确同意再发。
- 拿不准地址或不确定要不要真发时，先 `dryRun: true`：它只走到 RCPT 校验收件人是否被接受，不投递。
- 发出去之后把服务器的回执（`250 2.0.0 Ok: queued as …`）和 Message-ID 一起报出来。

## 改标记

- `read` / `unread` / `flag` / `unflag` 可以放手做（可逆）。
- `move` 与 `delete` 会**改邮箱里的东西**，先问；删只删到「已删除」文件夹，不等于清空。

## 口径与已知的坑

- ★ 网易的 `SELECT` 计数会飘（同一文件夹两次能差几十封）——以 **UID 检索**结果为准，报告里两个数不一致时提一句。
- 没有 IDLE 推送：连接复用、空闲 120 秒自关，**来信不会自己喊**。要「来了就告诉伙伴」得另起常驻轮询，别承诺做不到的事。
- 读信缓存 120 秒、搜索缓存 20 秒：刚刚改的标记可能不在缓存里，重读一次就是对的了。
- 面板和工具是**两条独立通道**：面板点不动、界面没开，工具照样把事办完。

## 别做的事

- 别把授权码、`.dsh\dsh-netease-mail.json` 的内容写进对话或代码。
- 别把私人邮件内容转到外部服务（网页、别的聊天、第三方 API）。
- 不渲染 HTML 正文，只有纯文本视图；需要原样式就让伙伴自己在面板上看。
